# ACP-VCF Prep Panel (Chrome Extension)

A side-panel companion for `claims.vcf.gov`. It shows the VCF account prep sheet generated by ACP-VCF so a paralegal can copy-paste each field into the official VCF portal. It deliberately **never fills or submits** the VCF form.

## What it does

- Injects a collapsible side panel on `https://www.claims.vcf.gov`.
- Loads prep sheets from the ACP-VCF backend (`http://localhost:5003` by default).
- One-click **Copy** buttons for every field.
- Drag-and-drop values from the panel onto VCF.gov input fields.

## Install / load (first time)

1. Open Chrome and go to `chrome://extensions/`.
2. Turn on **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked**.
4. Select this folder: `C:\vcf\chrome_extension_vcf`.
5. The extension **ACP-VCF Prep Panel** should appear in the extensions list.

## Configure

### Easy way — grab the token automatically

1. In ACP-VCF, log in at `http://localhost:5174`.
2. Click the extension icon in the Chrome toolbar.
3. Click **Grab token from ACP-VCF tab**.
4. Click **Save & test connection**.

### Manual way

1. In ACP-VCF, log in.
2. Open Chrome DevTools → **Application** → **Local Storage** → `http://localhost:5174`.
3. Copy the value of the **`paraiq_token`** key.
4. Click the extension icon in Chrome toolbar.
5. Paste the token into **JWT token**.
6. Backend URL should already be `http://localhost:5003`. If not, set it.
7. Click **Save & test connection**.

## Reload after code changes

Chrome does **not** auto-reload unpacked extensions when files on disk change.

### Option A — quick reload button
1. Go to `chrome://extensions/`.
2. Find **ACP-VCF Prep Panel**.
3. Click the circular **↻ Reload** icon on the card.
4. Hard-refresh the `claims.vcf.gov` tab (`Ctrl + F5` or `Cmd + Shift + R`).

### Option B — reload from the extension icon (if enabled)
1. Right-click the extension icon → **Manage extension**.
2. Click **Reload**.

### Option C — keyboard shortcut (requires pinning)
1. Pin the extension to the toolbar.
2. After changing files, click the extension icon and then reload the VCF tab.

> Tip: If the panel still shows old code, close and reopen the VCF.gov tab. Content scripts are reinjected only on page load.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Panel does not appear on VCF.gov | Make sure the extension is enabled and you are on `https://www.claims.vcf.gov`. Reload the extension and refresh the page. |
| "No token set" | Open the extension popup and click **Grab token from ACP-VCF tab**, then **Save**. |
| "Cannot reach http://localhost:5003" | Confirm the ACP-VCF backend is running on port 5003. |
| 401 / auth failed | The JWT has expired. Copy a new one from ACP-VCF and save it in the popup. |

## Files

- `manifest.json` — extension metadata and host permissions.
- `background.js` — service worker that proxies API calls to the ACP-VCF backend (avoids CORS).
- `content.js` — injects the side panel on `claims.vcf.gov`.
- `popup.html` / `popup.js` — settings popup for backend URL and JWT.
